# Om Siddha Sevabhavi Sanstha – Shri Govardhan Goshala

A responsive static website built with HTML, CSS, JavaScript and Bootstrap 5.

## Files
- `index.html` – page structure and Marathi/English content
- `style.css` – custom responsive styling
- `script.js` – navigation behavior, current year and back-to-top button
- `vercel.json` – Vercel static deployment configuration

## Run locally
Open `index.html` in a browser. For a local development server, use the VS Code Live Server extension.

## Deploy to Vercel
1. Extract the ZIP and place the files in a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Set Framework Preset to **Other**.
4. Leave Build Command and Output Directory empty (or use `.` as the output directory).
5. Click **Deploy**.

You can also install the Vercel CLI and run `vercel` from this folder.
